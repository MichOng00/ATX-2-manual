4.2.2.1 beep

It is "beep" signal generated function for the piezo speaker on the ATX2 controller board. Beep signal frequency should be select 4 frequencies (250, 506, 762 and 1,274Hz) with duration time 100 millisecond. ATX2 board will drive the sound signal to on-board piezo speaker.

Syntax

void beep(int beepType)

Parameter

beepType - beep frequency

0 or () : 1,274Hz

1 : 762Hz

2 : 506Hz

3 : 250Hz

Example 4-3

beep(1); // Generate the signal 762Hz with 100ms to  ATX2 speaker.
